Écran titre redessiné en français

Patcher la ROM

Applique le patch de traduction française directement en ligne, sur ta propre copie du jeu original.

Jeu original attendu : Bishoujo Senshi Sailor Moon (Japan).

Modifications apportées

Traduction faite depuis la version japonaise (le jeu n'est jamais sorti en Europe). Les noms sont ceux du dessin animé français : Bunny, Molly, Raya, Marcy, Mathilda, Bourdu, l'Homme Masqué, la Reine Béryl…

Ce qui est traduit

  • Tous les dialogues : 74 scènes avec les héroïnes, Luna, Artémis, les boss et l'Homme Masqué.
  • L'histoire d'ouverture (elle passe si on attend sur l'écran titre) et les 5 fins.
  • Écran titre (logo SAILOR MOON), choix de la guerrière, cartons des 5 niveaux, options, résultats, CONTINUER ? et PERDU !.
  • Police française accentuée, plus fine que les caractères japonais : environ deux fois plus de texte par bulle.

Améliorations

  • ROM « world » : le verrou de région est retiré, le jeu démarre sur toutes les Mega Drive.
  • Mode debug : A + START (tenus ensemble) sur l'écran titre affiche DEBUGMODE ON ; la guerrière devient invincible. Le jeu normal n'est pas changé.

Historique des versions

  • SMv02 (23/11/2026) : Mode debug : A + START sur l'écran titre affiche DEBUGMODE ON, la guerrière ne perd plus de vie
  • SMv01 (23/11/2026) : Première version : dialogues, histoire, fins, écran titre et tous les menus en français ; ROM world : démarre sur toutes les Mega Drive

Les patchs de traduction s'appliquent à ta propre copie du jeu original, directement dans ton navigateur : aucun jeu commercial n'est fourni et rien n'est envoyé sur Internet. Les jeux de Player Time sont offerts gratuitement.

Les jeux et leurs personnages appartiennent à leurs éditeurs respectifs (SEGA, Disney…). Traductions non officielles, réalisées par des fans.
