Phantasy Star II – Aventures textuelles

Traduction française (8 aventures + menu)

Mega DriveVersion de testVersion PSTAv18Mis à jour le 27/11/2026

L'écran titre de l'aventure de Nei

Patcher la ROM

Applique le patch de traduction française directement en ligne, sur ta propre copie du jeu original.

Jeu original attendu : Nei Adventure (Japan) (Sega Meganet).

Modifications apportées

Ce qui est traduit

  • Les textes des 8 aventures, traduits depuis le japonais (environ 3 100 textes)
  • Police française avec accents, lignes coupées proprement au mot
  • Écrans « Mode d'emploi », titres « L'AVENTURE DE ... » et logo du cadre
  • Bandeau PV / PA / MS (et PRISES dans l'aventure d'Amia)
  • Panneaux de direction NORD / SUD / EST / OUEST / HAUT / BAS
  • Un menu pour choisir l'aventure ; RESET revient au menu
  • Crédit « Traduction française : Player Time » à la fin de chaque aventure

À savoir

Le patch s'applique sur la ROM japonaise « Nei Adventure » et donne la compilation complète des 8 aventures. Les ROM séparées de chaque aventure sont aussi disponibles dans le dossier du projet.

Dans la compilation, la petite mémoire de sauvegarde de la cartouche est commune aux 8 aventures.

Historique des versions

  • PSTAv18 (27/11/2026) : Les cases des listes de choix sont plus larges : les noms d'objets et de lieux s'affichent en entier ; Les noms raccourcis dans la version précédente retrouvent leur forme complète (Tableau de bord, Canot gonflable...) ; Les sauvegardes des versions précédentes restent bonnes
  • PSTAv17 (27/11/2026) : Corrigé : dans les listes de choix, les noms trop longs débordaient de leur case (ex. « Tableau de bord » chez Amia) ; Ces noms ont été raccourcis dans les 8 aventures (Boîte à gants, Canot, Miroir à main...) ; Les sauvegardes de la version précédente restent bonnes
  • PSTAv16 (26/11/2026) : Mode d'emploi : une confirmation est demandée avant de sauvegarder et avant de revenir au menu
  • PSTAv15 (26/11/2026) : Corrigé : la sauvegarde ne marchait pas dans BlastEm
  • PSTAv14 (26/11/2026) : Corrigé : fausses disquettes et étoiles dans le menu sur les émulateurs sans mémoire de sauvegarde
  • PSTAv13 (26/11/2026) : Les 8 aventures peuvent être sauvegardées en même temps
  • PSTAv12 (26/11/2026) : Sauvegarde : dans le Mode d'emploi (START), A sauvegarde et C revient au menu ; Menu : reprendre une aventure sauvegardée, étoile sur les aventures terminées
  • PSTAv11 (26/11/2026) : Menu : la carte peut être activée ou coupée avec le bouton B
  • PSTAv10 (26/11/2026) : Nouvelle carte sur le bouton C : elle se dévoile au fur et à mesure des lieux visités, avec un curseur pour lire le nom des lieux
  • PSTAv09 (25/11/2026) : Mode debug caché : A + START sur le menu, puis B + START en jeu pour relire tous les textes de l'aventure dans la fenêtre du jeu
  • PSTAv08 (25/11/2026) : Menu : choix des noms des personnages, japonais (Yushis, Amia…) ou occidentaux comme dans la version anglaise de Phantasy Star II (Rolf, Anna…)
  • PSTAv07 (25/11/2026) : Menu : logo Phantasy Star II des jeux en haut de l'écran ; Menu : curseur devant l'aventure choisie, surbrillance corrigée ; Menu : musique de l'écran titre
  • PSTAv06 (25/11/2026) : Menu : petit bruit du curseur, le même que dans les jeux, quand on change d'aventure
  • PSTAv05 (25/11/2026) : Le menu affiche le portrait du héros choisi, dans un cadre à côté de la liste
  • PSTAv04 (25/11/2026) : Le texte ne défile plus tout seul : le jeu attend le bouton à chaque page pleine ; Panneaux de direction en français : NORD, SUD, EST, OUEST, HAUT, BAS ; Lettres « l » et « i » redessinées (plus de pixel bizarre)
  • PSTAv03 (25/11/2026) : Le menu présente les 8 aventures dans l'ordre de leur sortie : Amia, Shilka, Kains, Anne, Huey, Yushis, Rudger, Nei
  • PSTAv02 (24/11/2026) : Les phrases que le jeu assemble en plusieurs morceaux ne sont plus collées (espace manquante après un point, par exemple « Le quartier animé.À l'ouest »)
  • PSTAv01 (24/11/2026) : Première version : les 8 aventures textuelles de Phantasy Star II en français ; Compilation sur une seule cartouche avec un menu de choix ; Mode d'emploi, titres, logo et bandeau PV/PA/MS en français ; Fonctionne sur toutes les Mega Drive (ROM monde)
