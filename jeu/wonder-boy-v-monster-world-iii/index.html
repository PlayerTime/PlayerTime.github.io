Modifications apportées

Ce qui est traduit

  • Tous les dialogues, traduits depuis le japonais.
  • Les menus, les noms d'objets et le bandeau des objets obtenus.
  • L'écran titre et le générique de fin.
  • Une nouvelle police avec accents et minuscules, et des fenêtres de 5 lignes.
  • Ajout : les caractéristiques et effets des objets en boutique et dans le menu d'équipement (absents de la version japonaise).
  • Ajout : un MODE DIFFICILE au choix sur l'écran titre, avec les règles et les combats de la version occidentale (fin de partie à la mort, seuil de mort plus sévère, Roi des démons et boss final plus durs).
  • Ajout : un MODE DEBUG (maintenir A et appuyer sur START à l'écran titre, puis A dans le menu pause) : équipement, objets, magie, cœurs, or, invincibilité, caméra libre, téléportation.

Les noms des personnages et des lieux sont transcrits du japonais (Shion, Priscilla, Éléonora, Shappo, Alseido, Lilipat, Bargonia...).

La ROM fonctionne sur toutes les Mega Drive, y compris la Mega Drive Mini et la Mega SG.

Historique des versions

  • MW3v15 (18/11/2026) : Mode debug : on peut quitter la caméra libre par le menu pause (START)
  • MW3v14 (18/11/2026) : Mode debug : un reset l'éteint, avec la caméra libre et l'invincibilité
  • MW3v13 (18/11/2026) : Mode debug : la caméra libre se déplace avec la croix pour explorer la salle, sans bugs d'affichage
  • MW3v12 (18/11/2026) : Correction d'un plantage du mode debug (option « Cœurs max ») ; Le mode debug donne désormais 14 cœurs, le maximum du jeu
  • MW3v11 (18/11/2026) : Nouveau : mode debug (A + START à l'écran titre) ; Menu de debug dans le menu pause (A sur l'écran CHOIX) : équipement, objets, magie, cœurs, or, invincibilité, caméra libre, téléportation, choix du mode
  • MW3v10 (18/11/2026) : Boutiques : description des lances raccourcie (« Arme à deux mains. »)
  • MW3v09 (18/11/2026) : Menu d'équipement : le nom entier de l'objet choisi clignote, même pour les noms longs
  • MW3v08 (18/11/2026) : Écran titre : le choix MODE FACILE / MODE DIFFICILE est posé après NOUVELLE PARTIE ; Le mode choisi est enregistré dans la sauvegarde
  • MW3v07 (18/11/2026) : Boutiques : chaque paire de bottes indique son vrai effet (vitesse de marche, hauteur de saut) ; Boutiques : les Bottes de cuir et de grès n'affichent plus « Aucun bonus » ; Boutiques : les lances précisent qu'elles frappent plus loin
  • MW3v06 (18/11/2026) : Mode difficile : la tête de lapin du Roi des démons lâche des flammes, comme en version occidentale ; Mode difficile : boss final avec sol qui défile, scie et tirs qui visent Shion, comme en version occidentale ; Mode difficile : le téléporteur étoilé du château du Roi des démons fonctionne comme en version occidentale
  • MW3v05 (18/11/2026) : Correction reprise de la version occidentale : quand Shion est rapetissé, le menu affiche ses vraies caractéristiques du moment
  • MW3v04 (18/11/2026) : Nouveau : choix de la difficulté sur l'écran titre (NOUVELLE PARTIE ou MODE DIFFICILE) ; Mode difficile : à la mort, écran « Fin de partie » et retour au titre au lieu de l'auberge, comme dans la version occidentale ; Mode difficile : on meurt dès qu'il reste moins d'un quart de cœur, comme dans la version occidentale ; Le mode choisi est enregistré avec la sauvegarde
  • MW3v03 (18/11/2026) : En boutique, le marchand indique les caractéristiques (ATT/DÉF/VIT en étoiles) et l'effet de l'objet avant le prix ; Dans le menu d'équipement, les caractéristiques de chaque objet s'affichent au-dessus de son nom
  • MW3v02 (18/11/2026) : Noms des personnages et des lieux repris de la version japonaise : Éléonora, Shappo, Alseido, Lilipat, Bargonia, désert de Mâmu, Purapril Sheila, Champi-fantôme
  • MW3v01 (18/11/2026) : Première version : dialogues, menus, écran titre et générique en français ; Nouvelle police accentuée et fenêtres de dialogue de 5 lignes
