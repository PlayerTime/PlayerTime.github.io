Modifications apportées

La traduction

Ristar n'a jamais eu de version française : la version européenne était en anglais, et la version japonaise ne contient pas de texte japonais.

Tous les textes du jeu ont été traduits, et les cartons « Round / Planet » ont été redessinés en « Monde / Planète ».

  • Fonctionne sur toutes les Mega Drive (japonaise, américaine, européenne), Mega Drive Mini et Mega SG.
  • Textes en majuscules sans accents (la police du jeu n'en a pas).
  • Les mots de passe du jeu restent les mêmes (ILOVEU, DOFEEL, MUSEUM...).
  • Bonus : mot de passe DEX pour voler librement dans les niveaux (B + Start en jeu).
  • Bonus : mot de passe VOLT pour le ralenti (A + Start en jeu).

Historique des versions

  • RISv07 (06/11/2026) : Traduit : décompte des bonus en fin de monde (BONUS FIN DE MONDE, BONUS TRESOR, BONUS TECHNIQUE, BONUS SECRET, TOTAL) ; Vérification complète des textes restés en anglais
  • RISv06 (06/11/2026) : Traduits : bonus de hauteur (BONUS SOMMET), DEMO, RECORD et PIRE SCORE
  • RISv05 (06/11/2026) : Nouveau mot de passe VOLT : ralenti (fonction de test cachée). En jeu, maintenir A et appuyer sur Start pour l'allumer ou l'éteindre
  • RISv04 (06/11/2026) : Option VIES retirée (le jeu fixe les vies selon la difficulté) ; menu des options d'origine rétabli ; Apostrophes supprimées (mauvais affichage dans le Théâtre sonore)
  • RISv03 (06/11/2026) : Nouveau mot de passe DEX : déplacement libre (mode debug caché). En jeu, maintenir B et appuyer sur Start pour voler, Start pour revenir
  • RISv02 (06/11/2026) : Correction du bug « SON COUPE » du Théâtre sonore (l'oiseau tombe de nouveau) ; Option cachée « VIES 1/3/5/7 » réactivée dans les options ; Les 7 mots de passe japonais retirés de la version occidentale (CANDY, FEEL, AAAAAA, STAR, VALDI, MASTER, MACCHA) fonctionnent de nouveau
  • RISv01 (06/11/2026) : Première version : intro, menus, options, codes secrets, Sound Theater, choix du monde, zone bonus, boss, générique traduits ; Cartons de début de monde redessinés (MONDE / PLANETE) ; Crédit de traduction dans le générique de fin
