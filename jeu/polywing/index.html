À propos du jeu

Le jeu

Des machines tombent du ciel sur ta planète. Elles viennent d'un cœur de métal caché sous la lave d'une planète lointaine. Un seul vaisseau peut l'atteindre : le Polywing.

Le jeu complet compte dix niveaux et six boss. La démo s'arrête après le Ver des sables.

Dans la démo

  • L'introduction et trois niveaux : la planète verte, une zone bonus dans l'espace, les dunes
  • Deux boss : le Gardien et le Ver des sables
  • Tempête de sable, anneaux à enchaîner, bombes, bouclier, double tir
  • Trois continues par partie, record sauvegardé

Commandes

  • Croix : déplacer le vaisseau
  • A : tirer. A maintenu : viser et charger, puis relâcher pour lancer la bombe
  • B + gauche ou droite : voler sur la tranche. B + deux fois gauche ou droite : tonneau, qui renvoie les tirs
  • C + haut ou bas : accélérer ou freiner (garder C pour conserver la vitesse). C + deux fois haut : looping
  • Start : pause

Historique des versions

  • Démo V02 (12/11/2026) : Le logo Player Time et sa voix au démarrage (Start pour le passer) ; Introduction : le cœur de métal est montré dans sa salle, au fond du tunnel ; Les dunes ont leur propre ciel : deux soleils et des plateaux rocheux ; L'image du jeu prend toute la largeur de l'écran : plus de bandes à gauche et à droite ; Dans l'espace, la planète de destination grossit à mesure qu'on s'en approche ; Niveaux bien plus longs : environ 2 minutes chacun avant le boss ; Des arches à franchir : en passer quatre d'affilée fait apparaître un objet ; Frein sur C seul, accélération sur deux appuis rapides sur C ; manette 6 boutons : Z accélère, X fait le looping ; A tenu : visée et salve sur les ennemis accrochés ; deux appuis sur A tenu : la bombe (Y sur manette 6 boutons) ; Des escadrilles restent devant le vaisseau : les abattre toutes d'une même salve donne un combo ; Le décor s'incline avec le vaisseau dans les virages
  • Démo V01 (11/11/2026) : Première démo publique : trois niveaux et deux boss
