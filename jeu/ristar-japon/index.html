Modifications apportées

La traduction

La version japonaise de Ristar est différente de la version occidentale : intro sans texte, noms des planètes (Neer, Leatow, Onaclove...), trésors des niveaux bonus nommés, fin et générique propres.

Cette traduction part de la ROM japonaise et garde toutes ces différences. Une autre traduction existe pour la version US/Europe.

  • Fonctionne sur toutes les Mega Drive, Mega Drive Mini et Mega SG.
  • Textes en majuscules sans accents (la police du jeu n'en a pas).
  • Cartons de début de monde redessinés en « MONDE / PLANETE ».
  • Bonus : mot de passe DEX pour voler librement dans les niveaux (B + Start en jeu).
  • Bonus : mot de passe VOLT pour le ralenti (A + Start en jeu).

Historique des versions

  • RISJv07 (06/11/2026) : Traduit : décompte des bonus en fin de monde ; Verrou de région retiré : démarre enfin sur toutes les consoles (les versions précédentes ne marchaient que sur console japonaise) ; Vérification complète des textes restés en anglais
  • RISJv06 (06/11/2026) : Traduits : bonus de hauteur (BONUS SOMMET), DEMO, RECORD et PIRE SCORE
  • RISJv05 (06/11/2026) : Nouveau mot de passe VOLT : ralenti (fonction de test cachée). En jeu, maintenir A et appuyer sur Start pour l'allumer ou l'éteindre
  • RISJv04 (06/11/2026) : Option VIES retirée (le jeu fixe les vies selon la difficulté) ; menu des options d'origine rétabli
  • RISJv03 (06/11/2026) : Nouveau mot de passe DEX : déplacement libre (mode debug caché). En jeu, maintenir B et appuyer sur Start pour voler, Start pour revenir
  • RISJv02 (06/11/2026) : Correction du bug « SON COUPE » du Théâtre sonore (l'oiseau tombe de nouveau) ; Option cachée « VIES 1/3/5/7 » réactivée dans les options
  • RISJv01 (06/11/2026) : Première version : menus, codes secrets, choix du monde, zone bonus et trésors, boss, fin du jeu, Sound Theater et générique traduits ; Cartons de début de monde redessinés (MONDE / PLANETE) ; Crédit de traduction dans le générique de fin
