    Mega Drive : .bin, .gen, .md, .smd ou .zip.
    Mega CD : le .cue avec tous ses .bin (choisis-les ensemble), un .chd, un .iso, ou un .zip qui les contient.
    Tes fichiers restent sur ton appareil, rien n'est envoyé.
    Si une traduction française Player Time existe pour ce jeu, l'émulateur la propose tout seul.

    Réglages

    BIOS Mega CD

    Le Mega CD a besoin du BIOS de la console (le programme de démarrage de Sega). Ajoute le tien une fois : il reste sur ce téléphone et n'est jamais envoyé. Europe, USA, Japon : un seul suffit, mais chaque disque préfère le BIOS de sa région.

    Sur iPhone : bouton Partager → « Sur l'écran d'accueil » pour l'avoir comme une appli.
